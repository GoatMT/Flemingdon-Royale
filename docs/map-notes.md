# Flemingdon Park map notes

The map is a real-world-scale 2.2 km square where one world unit represents approximately one metre. It uses clipped geometry from the City of Toronto's 2025 3D Massing shapefile, Toronto Centreline Version 2, Sidewalk Inventory, Green Spaces, and tree-location datasets. The current bounds contain 1,012 building features, 364 road/trail segments, 312 sidewalk paths, 19 named greenspace groups, 21 school/library/park/recreation points, and 11,209 mapped tree points with derived heights. Named drop points read coordinates from the landmark records. Tree points render as spatially batched, smooth, varied 3D canopies and trunks; close matches to the street-tree inventory supply species forms. Building roofs keep their mapped outlines and mapped average height; road widths are class-based, while sidewalks, parks, and landmarks use the City's published geometry.

The 3D Massing dataset is provided for illustrative context, and the City disclaims completeness and accuracy. The buildings are neighborhood-wide massing models, not surveyed facades or interiors; the window grid is a visual treatment. Sidewalk lines were interpreted from spring 2015 aerial photography, so they may omit newer work or be out of date; each is rendered at an approximate 1.8 m width. Tree location and height come from the physical tree-point layer, which does not contain species. Species are attached only when a street-tree inventory point falls within five metres. The City warns that street-tree points can be geocoded to parcel addresses and may be inaccurate, so unpaired trees use generic visual forms and close species matches remain approximate. Terrain is a flat gameplay base because the Ontario elevation image service returned no raster samples for the map crop; the ravine's real slopes are not modeled. The gameplay boundary is a square clip around the neighborhood. Landmark marker rings shift only when needed to keep a marker from disappearing inside a building footprint. A player drops into safe ground near the chosen landmark's official coordinate.

Google Earth/Maps imagery is not used as source geometry. Google's terms prohibit tracing or digitizing features from its imagery for derivative maps and prohibit creating 3D models from Google Maps content; the map uses licensed government datasets instead.

Sources: [City of Toronto 3D Massing](https://open.toronto.ca/dataset/3d-massing/), [Toronto Centreline (TCL)](https://open.toronto.ca/dataset/toronto-centreline-tcl/), [Sidewalk Inventory](https://open.toronto.ca/dataset/sidewalk-inventory/), [Green Spaces](https://open.toronto.ca/dataset/green-spaces/), [physical tree locations](https://open.toronto.ca/dataset/topographic-mapping-physical-location-of-trees/), [Street Tree Data](https://open.toronto.ca/dataset/street-tree-data/), [School Locations](https://open.toronto.ca/dataset/school-locations-all-types/), [Toronto Public Library branches](https://open.toronto.ca/dataset/library-branch-general-information/), and [Parks and Recreation Facilities](https://open.toronto.ca/dataset/parks-and-recreation-facilities/).
